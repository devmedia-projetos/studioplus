# Studio Plus

Landing page do Studio Plus, um estúdio digital especializado em design de interface, desenvolvimento web e sites responsivos, com apresentação de serviços, avaliações de clientes e formulário de contato.

## Tecnologias

HTML e CSS.

## Estrutura de arquivos

- `index.html`: página principal com apresentação do estúdio, serviços, avaliações, parceiros e formulário de contato
- `style.css`: estilos gerais do projeto
- `assets/`: imagens utilizadas no projeto

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
